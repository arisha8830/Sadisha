## ⚙️ Technical Highlights

### 1. Contact Form Backend (Web3Forms API)
- Form submissions are routed asynchronously through Web3Forms API to: `arishapriyashan2@gmail.com`.
- Zero-backend setup running entirely on client-side JavaScript (`fetch()`).
- Form validations with user-friendly error and success banners.

### 2. Search Engine Optimization (SEO)
- **JSON-LD Schema Markup**: Declares business as an `EngineeringBusiness` with contact info and geo-location.
- **Open Graph Protocol**: Enables rich link previews across Facebook, WhatsApp, and social media.
- **Search Engine Discovery**: Full integration with `robots.txt` and `sitemap.xml`.
- **Google Search Console**: Verified and ready for organic indexing.
